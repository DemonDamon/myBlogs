## 关键发现汇总

### 架构模式
1. **Orchestrator-Worker**: Anthropic 官方采用的模式
2. **Swarm Architecture**: LangGraph 提出的动态控制传递
3. **Agents as Tools**: AWS 提出的包装模式
4. **Sequential Pipeline**: Google ADK 的基础模式

### 通信协议
1. **MCP (Model Context Protocol)**: 模型上下文协议
2. **ACP (Agent Communication Protocol)**: Agent 通信协议
3. **A2A (Agent-to-Agent)**: Agent 对 Agent 协议
4. **ANP (Agent Network Protocol)**: Agent 网络协议
5. **AG-UI (Agent Graph User Interface)**: Agent 图形用户界面

### 性能数据
- 多Agent系统比单Agent性能提升 **90.2%**（Anthropic 内部评估）
- Agent 通常比聊天交互多使用 **4倍** tokens
- 多Agent系统比聊天多使用 **15倍** tokens
- Claude Sonnet 4 是 Claude Sonnet 3.7 的 **更大性能提升**，超过翻倍 token 预算

### 关键设计原则
1. **Think like your agents**: 理解 agent 的行为模式
2. **Teach the orchestrator how to delegate**: 教会协调器如何委派
3. **Scale effort to query complexity**: 根据查询复杂性扩展工作量
4. **Tool design and selection are critical**: 工具设计和选择至关重要
5. **Let agents improve themselves**: 让 agent 自我改进
6. **Start wide, then narrow down**: 先宽后窄的搜索策略
7. **Guide the thinking process**: 引导思维过程
8. **Parallel tool calling transforms speed**: 并行工具调用改变速度
