[主题与布局设想]
展示 PageIndex 推理式检索机制的时序图。水平排列三个参与者：用户（左侧）、系统（中间）、LLM（右侧）。采用从左到右的时间线布局，体现用户提问 → 系统调度 → LLM 推理 → 系统提取 → LLM 生成 → 用户获得答案的完整交互流程。背景为干净的纯白，强调消息传递的清晰可追溯性。

[视觉模块详解]

Section A — 参与者与布局：
1. **三个参与者**：左侧为「用户」简笔画或人形图标；中间为「系统」矩形框；右侧为「LLM」图标（如机器人或大脑）。三者用垂直虚线分隔，形成清晰的泳道。

Section B — 消息序列（自上而下）：
2. **用户提问**：用户向系统发出箭头，标注「提问」。
3. **系统转发**：系统向 LLM 发出箭头，标注「问题 + 树结构（标题/摘要）」。
4. **LLM 推理**：LLM 向系统返回箭头，标注「思考过程 + 相关 node_id 列表」。
5. **系统自处理**：系统内部的自调用箭头（虚线或折线），标注「根据 node_id 提取节点全文」。
6. **二次请求**：系统向 LLM 发出箭头，标注「问题 + 节点全文作为上下文」。
7. **最终答案**：LLM 向用户返回箭头，标注「生成答案（含页码/章节引用）」。

Section C — 视觉元素：
- 请求箭头：实线，从左到右或从上到下。
- 返回箭头：虚线或不同颜色，表示响应。
- 系统自调用：虚线或 U 形折线，表示内部处理。

[风格与配色方案]
扁平化矢量风格。用户端用蓝色系，系统用灰色系，LLM 用绿色系。箭头采用实线表示请求、虚线表示响应。字体使用无衬线黑体，中文标签。保持时序图的标准符号（参与者、生命线、消息箭头）。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
