# Cursor 动态上下文工程管理的秘诀

> **发布时间**：2026年1月8日 08:02

## TL;DR

Cursor 采用**动态上下文发现（Dynamic Context Discovery）** 策略替代传统的静态上下文注入，核心思想是：

> 预先提供更少的细节，让 Agent 自主按需提取相关上下文。

实测效果：MCP 工具的动态加载策略使 **Agent 总 token 消耗减少 46.9%**。

---

## 一、核心概念：静态上下文 vs 动态上下文

| 类型 | 定义 | 问题 |
|------|------|------|
| **静态上下文** | 始终被包含在 prompt 中的固定信息 | 占用 token、可能造成混淆或矛盾 |
| **动态上下文** | Agent 按需提取的相关信息 | token 效率高、回复质量更好 |

**动态上下文发现的优势**：
- 只将必要数据引入上下文窗口
- 减少可能造成混淆或矛盾的信息量
- 提升 Agent 回复质量

---

## 二、Cursor 的 5 大动态上下文策略

### 策略 1：将较长的工具响应转换为文件

**问题**：第三方工具（shell 命令、MCP 调用）可能返回巨大的 JSON 响应，显著增加上下文窗口大小。

**常见做法**：截断较长输出 → 可能丢失重要信息。

**Cursor 做法**：
1. 把输出写入文件
2. 赋予 Agent 读取该文件的能力
3. Agent 调用 `tail` 检查末尾内容
4. 如有需要再继续向后读取更多内容

**收益**：在接近上下文上限时减少不必要的额外总结。

---

### 策略 2：在摘要过程中引用对话历史

**问题**：当上下文窗口被填满时，Cursor 触发摘要步骤，但摘要是**有损压缩**，Agent 可能忘记关键细节。

**Cursor 做法**：
1. 将对话历史作为**文件**提供
2. 摘要后给 Agent 一个指向历史文件的引用
3. Agent 可在历史中搜索找回摘要中缺失的细节

**触发时机**：
- 自动：达到上下文窗口上限
- 手动：用户主动触发 `/summarize`

---

### 策略 3：支持 Agent Skills 开放标准

**Agent Skills** 是一种用于为编码 Agent 扩展专用能力的**开放标准**。

**特点**：
- 由文件定义（类似 Rules）
- 包含名称和描述（作为静态上下文）
- 可打包可执行文件或脚本

**动态发现方式**：
- 使用 `grep` 搜索
- 使用 Cursor 的语义搜索自动引入相关 Skills

---

### 策略 4：高效地仅加载所需的 MCP 工具

**问题**：
- MCP 服务器包含很多工具，描述往往很长
- 即使始终包含在提示中，大部分工具实际不会被使用
- 多个 MCP 服务器会进一步放大问题

**Cursor 做法**：
1. 将工具描述同步到一个文件夹
2. Agent 只收到一小段静态上下文（工具名称）
3. 任务需要时再去查找具体工具

**实测数据**：

![MCP Token 对比图](images/99a3cf9bbf7f2c3066316030ede9f3f8.jpg)

> 在会调用 MCP 工具的运行中，这一策略将 Agent 的**总 token 消耗减少了 46.9%**  
> （统计显著，但会随已安装 MCP 数量产生较大波动）

**额外收益**：可向 Agent 传达 MCP 工具的状态（如需要重新认证时主动提示用户）。

---

### 策略 5：将所有集成终端会话视为文件

**之前**：需要把终端输出复制粘贴到 Agent 输入中。

**现在**：Cursor 自动将集成终端的输出同步到本地文件系统。

**好处**：
- 可轻松询问"为什么我的命令失败了？"
- Agent 可只对相关输出进行 `grep`
- 对长时间运行进程（如服务器日志）特别有用
- 动态发现而非静态注入

---

## 三、核心设计哲学：文件作为简单抽象

> 目前还不清楚，文件是否会成为基于 LLM 的工具的最终接口形式。  
> 但随着编码 Agent 的快速发展，**文件一直是一种简单而强大的原语**，相比再造出一种无法充分兼顾未来的抽象层，也是更安全的选择。

**Cursor 的文件化策略统一了**：
- 工具响应 → 文件
- 对话历史 → 文件
- Agent Skills → 文件
- MCP 工具描述 → 文件
- 终端会话 → 文件

---

## 四、可落地实践清单

| 场景 | 传统做法 | 动态上下文做法 |
|------|----------|----------------|
| 长工具响应 | 截断 | 写入文件 + `tail` 按需读取 |
| 对话历史 | 直接压缩丢弃 | 保留文件引用 + 搜索回查 |
| Agent 能力扩展 | 全部注入 prompt | Skills 文件 + 语义搜索 |
| MCP 工具 | 全部工具描述注入 | 仅名称 + 按需查找描述 |
| 终端输出 | 复制粘贴 | 自动同步文件 + `grep` |

---

## 五、关键数据点

- **46.9%**：MCP 动态加载策略减少的 Agent 总 token 消耗
- **文件**：Cursor 统一采用的上下文载体抽象
