[主题与布局设想]
展示三种注意力机制的状态更新对比，采用水平三列对比布局（左→中→右）。标题"三种注意力机制的记忆更新对比"居中置顶。三列分别对应：标准 Softmax Attention、线性注意力（加法更新）、Gated DeltaNet（Delta Rule + 门控）。每列内部垂直展示数据流和公式。

[视觉模块详解]
1. **标题栏**: "注意力机制演进对比"，白色文字，深蓝色背景条

2. **左列 — 标准 Softmax Attention（红色系）**:
   - 顶部标签："标准 Softmax Attention"（红色底色）
   - 中部数据流图：
     - Q、K 两个蓝色小矩形向下箭头连接到一个大矩形"注意力矩阵 n×n"（红色半透明，标注"O(n²)"）
     - 注意力矩阵向下箭头连接到 V 矩形，输出 O
   - 下方文字框："∑αᵢⱼ = 1（强制归一化）"
   - 底部红色警告标签："⚠️ 首Token注意力占46%（Attention Sink）"

3. **中列 — 线性注意力 / 加法更新（黄色系）**:
   - 顶部标签："线性注意力（加法更新）"（黄色底色）
   - 中部数据流图：
     - 一个矩形状态盒 S（黄色），标注"d×d 固定大小"
     - 上方箭头标注"S = S + kvᵀ"（加法符号高亮）
     - 右侧小字"O(nd²)"
   - 下方示意：三个小方块叠加在 S 上（越来越拥挤），标注"只增不减"
   - 底部黄色警告标签："⚠️ 旧记忆无法覆盖，检索混乱"

4. **右列 — Gated DeltaNet（绿色系，重点高亮）**:
   - 顶部标签："Gated DeltaNet"（绿色底色，加星号 ⭐）
   - 中部数据流图：
     - 状态矩阵 S（绿色），标注"d×d 固定大小"
     - 上方公式框（白底黑字）："S = (I - βkkᵀ)·S + βkvᵀ"
     - 公式中"(I - βkkᵀ)"部分用红色虚线框标注"擦除旧记忆"
     - "βkvᵀ"部分用绿色虚线框标注"写入新记忆"
     - 右侧箭头向下，经过一个金色菱形"σ(·) Sigmoid 门控"
     - 门控输出标注"逐元素过滤"
   - 底部绿色标签："✅ 可覆盖记忆 + 稀疏过滤 + 无 Attention Sink"

5. **底部对比总结栏**: 水平表格，四列：
   | 特性 | Softmax | 线性+加法 | Gated DeltaNet |
   | 复杂度 | O(n²d) | O(nd²) | O(nd²) |
   | 记忆管理 | 无状态 | 只增不减 | 可覆盖 |
   | Attention Sink | 严重 | 无 | 无 |
