[主题与布局设想]
展示 Agent Skill（静态工具）与 GEP Gene（动态基因）的核心对比，采用左右对称的双栏布局。左侧代表"传统 Skill"，右侧代表"GEP Gene"，中间用竖向分隔线区分，顶部各有一个大图标象征两种范式。整体背景浅灰白（#f5f7fa），强调对比清晰度。

[视觉模块详解]

Section A — 左侧栏（传统 Skill，蓝灰色调 #4a6fa5）：
- 顶部图标：员工手册/工具箱图标，圆形蓝灰色底
- 大标题："Agent Skill"，副标题："静态工具"
- 以下 6 个对比维度，每行一个圆角矩形标签条：
  1. 本质 → "代码片段（Function）"
  2. 创建者 → "人类开发者"
  3. 生命周期 → "手动部署 / 手动更新"
  4. 状态 → "静态 — 部署后不变"
  5. 错误处理 → "重复同一错误"
  6. 类比 → "📋 员工手册"
- 底部用浅蓝色背景包裹

Section B — 右侧栏（GEP Gene，绿紫渐变色调 #6c63ff → #4caf85）：
- 顶部图标：DNA 双螺旋/进化树图标，圆形渐变底
- 大标题："GEP Gene"，副标题："动态基因"
- 以下 6 个对比维度，每行一个圆角矩形标签条（绿色/紫色高亮）：
  1. 本质 → "数据结构（代码 + 元数据 + 历史）"
  2. 创建者 → "Evolver 引擎（AI 生成）"
  3. 生命周期 → "自动诞生 / 进化 / 退役"
  4. 状态 → "动态 — 随使用持续进化"
  5. 错误处理 → "触发变异（Mutation）自我修复"
  6. 类比 → "🧠 工作经验"
- 底部用浅绿色背景包裹

Section C — 中间分隔区：
竖向分隔线，中心位置放置 "VS" 徽章（圆形，橙色背景 #f0a500，白色粗体文字"VS"）

Section D — 底部总结条：
横跨全宽的横幅，深色背景（#1a1f2e），白色文字："从 Skill-Based 到 Evolution-Based —— AI 工程的下一个里程碑"

[风格与配色方案]
扁平化对比图风格，左侧冷色调（蓝灰）对应"静态/保守"，右侧暖绿渐变对应"动态/进化"。标签条使用圆角矩形，左侧浅蓝填充，右侧渐变填充。整体干净、专业，适合技术博客配图。字体无衬线黑体，维度标题加粗。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
