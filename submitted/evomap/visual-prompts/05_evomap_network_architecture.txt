[主题与布局设想]
展示 EvoMap 去中心化基因库的全球 Agent 运行时网络架构，采用从上到下的垂直分层布局。顶部为全球网络总览，中间为三层协议栈（区块链层、P2P 层、智能合约层），底部为分布在全球各地的 Agent 节点。整体背景为深色科技感底板（深蓝灰 #1a1f2e），强调去中心化、可追溯、激励透明的系统特性。

[视觉模块详解]

Section A — 顶部总览区（横跨全宽的圆角矩形容器）：
- 主标题："全球 Agent 运行时网络"
- 背景色：深蓝渐变（#0d1b2a → #1a2744）
- 边框：细发光蓝线，营造网络边界感

Section B — 三层协议栈（从上到下，三个并排矩形块，左侧为层名称，右侧为功能标注）：

1. 【区块链层】- 深紫色块（#4a148c），左侧图标：链式节点
   - 主文字："BFT 共识 + Merkle 证明"
   - 右侧箭头指向标注："进化事件溯源"

2. 【P2P 对等网络】- 青蓝色块（#0277bd），左侧图标：网状连接
   - 主文字："P2P 对等网络"
   - 右侧箭头指向标注："基因库分布式存储"

3. 【智能合约层】- 绿色块（#2e7d32），左侧图标：合约文档
   - 主文字："基因评分 + 收益分配"
   - 右侧箭头指向标注："贡献者激励"

Section C — 连接箭头区：
从三层协议栈向下延伸三条粗实线箭头，汇聚后分散指向底部各 Agent 节点，体现"协议支撑 Agent"的层级关系。

Section D — 底部 Agent 节点区（水平排列的圆角矩形节点）：
- Agent-A（东京）- 蓝色节点，带小图标
- Agent-B（深圳）- 绿色节点
- Agent-C（伦敦）- 紫色节点
- 省略号 "..." 表示更多节点
- Agent-N（硅谷）- 橙色节点

每个节点下方标注地理位置（东京、深圳、伦敦、硅谷），节点之间用虚线表示 P2P 连接。

Section E — 右侧五步流程说明（可选，竖排小卡片）：
若画面空间允许，在右侧用竖排标签简要标注基因进化落地的五步：
1. 本地固化 → .gene.json
2. 签名与哈希 → 不可篡改
3. P2P 同步 → libp2p 100+ 节点
4. 智能合约记账 → 贡献/采用/效能
5. 可追溯血脉 → 双亲基因 + 变异历史

[风格与配色方案]
深色科技主题，主色调为深蓝灰底板。三层协议栈使用紫/蓝/绿区分功能域，底部 Agent 节点使用多彩色块表示全球分布。箭头采用渐变色（蓝→青→绿），体现数据与基因的流动。整体风格：区块链 + 分布式系统架构图，专业学术论文图表风格。字体使用无衬线中文黑体。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
