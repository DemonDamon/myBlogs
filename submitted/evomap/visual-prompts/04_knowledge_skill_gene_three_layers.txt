[主题与布局设想]
展示 EvoMap 的「知识-技能-基因」三层抽象架构，采用从下到上的金字塔/层叠矩形布局，同时在右侧展示三层之间的作用链（动作流箭头）。背景深蓝（#0d1b2a），整体呈现基础设施"地层"的稳定感。

[视觉模块详解]

Section A — 三层堆叠矩形（从下到上，宽度递减）：

底层 — 【知识 Knowledge】（最宽，深绿色 #2d6a4f，高度较矮）：
- 图标：书本/数据库圆柱
- 主标题："知识 Knowledge"
- 描述文字（白色小字）："事实与约束的集合：公式、常识边界、工具行为模式"
- 右侧示例标签（黄色圆角标签）："物理公式 | API 调用规范 | 错误类型库"

中层 — 【技能 Skill】（中等宽度，紫蓝色 #4361ee，高度中等）：
- 图标：齿轮/扳手
- 主标题："技能 Skill"
- 描述文字（白色小字）："可执行过程模块：建模、求解、Traceback修复、断言注入、维度检查"
- 右侧示例标签（青色圆角标签）："shell_exec | disk_check | image_convert"

顶层 — 【基因 Gene】（最窄，金色渐变 #f0a500→#ffd700，高度较高，最显眼）：
- 图标：DNA 双螺旋
- 主标题："基因 Gene"
- 描述文字（白色小字）："决策偏置与工作流编排：何时触发哪个技能、顺序、阈值、停止条件"
- 右侧示例标签（橙色圆角标签）："gene_repair_from_errors | gene_innovate | gene_memory_bridge"

Section B — 右侧作用链（三层右侧，垂直箭头+文字标注）：
- 从 Knowledge 指向 Skill 的向上箭头：标注"提供正确性依据"
- 从 Skill 指向 Gene 的向上箭头：标注"转化为可执行动作"
- 在 Gene 层旁边添加向右弧形箭头，指向输出框：标注"编排默认策略，输出可复用结构"

Section C — 右侧输出效果框（圆角矩形，亮绿色边框）：
标题："工程效果"，内容：
- ✓ Token 显著减少
- ✓ 输出稳定性提升
- ✓ 得分持续上升

Section D — 底部注释条（横跨全宽，深色背景）：
白色文字："大量重复脚手架、试错、解释性内容 → 内化为默认工作流 → 仅输出最终可判决产物"

[风格与配色方案]
深色科技底板，三层使用绿/蓝/金渐变色系，从底部到顶部颜色越来越醒目，视觉重心在顶部"基因"层。层与层之间用渐变过渡区域衔接。整体风格：地质层叠+科技感，强调"从原材料到精华提炼"的隐喻。字体无衬线中文黑体。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
