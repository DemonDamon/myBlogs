[主题与布局设想]
展示 OpenClaw + EvoMap 在 CritPt 物理求解基准测试中的版本进化准确率折线图，同时叠加 Token 消耗趋势曲线。采用标准统计图表布局：横轴为版本迭代（Beta → v1.0 → v2.0 → v2.1 → v2.2），左纵轴为准确率（%），右纵轴为 Token 消耗（相对值）。背景浅灰白，风格专业学术。

[视觉模块详解]

Section A — 坐标系：
- 横轴（X轴）：5个版本节点，从左到右依次标注：Beta、v1.0、v2.0、v2.1、v2.2
- 左纵轴（Y轴左）：准确率 0%～25%，刻度步长 5%，轴标签"准确率 (%)"，绿色
- 右纵轴（Y轴右）：Token 消耗相对指数（低→高），轴标签"Token 消耗（相对值）"，橙色

Section B — 准确率折线（绿色实线，粗，带数据点标注）：
- Beta: 0.00% → 数据点用红色圆点标注，旁边小字"0.00%（仅能对话，无法计算）"
- v1.0: ~5% → 绿色圆点，小字"建立可交付基线"
- v2.0: ~12% → 绿色圆点，小字"自修复闭环形成"
- v2.1: 17.14% → 绿色圆点，小字"17.14%"，加粗
- v2.2: 18.57% → 绿色星形大数据点（强调最优），旁边红色标注框"最高分 18.57%\ntimeout_rate=0"

折线整体呈上升趋势，v2.2 点用星形+光晕效果强调。

Section C — Token 消耗折线（橙色虚线，细，带三角形数据点）：
- Beta → v1.0 → v2.0：Token 持续上升（显式推理阶段，需要大量文字输出）
- v2.0 → v2.2：Token 明显下降（工作流固化为基因，无需重复脚手架）
- 在折线顶峰处（约 v2.0）添加注释气泡："Token 先升后降 = 学习已发生的信号"

Section D — 版本说明标注条（图表底部，横向时间轴下方）：
每个版本下方用浅色背景小卡片标注核心基因：
- Beta：无主基因
- v1.0：gene_gep_innovate_from_opportunity（创新基因）
- v2.0：gene_gep_repair_from_errors（修复基因）
- v2.1：gene_test_driven_development（测试基因）
- v2.2：gene_active_research（研究基因）

Section E — 图表标题区（顶部）：
大标题："CritPt 基准评测：EvoMap 进化版本准确率追踪"
副标题（灰色小字）："数据来源：EvoMap 官方评测报告 2026.02"

[风格与配色方案]
学术论文图表风格。准确率曲线用绿色系（#4caf85），Token 曲线用橙色系（#f0a500），背景浅灰白（#f9fafb），网格线细灰色虚线，整体简洁专业。数据点标注文字用深灰色，重点数据（18.57%）用醒目红框或金色边框强调。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
