[主题与布局设想]
展示 Anthropic 双阶段 Agent 执行流程图，采用从左到右的水平流布局。分为两大区域：左侧"Initializer Agent（首轮奠基）"和右侧"Coding Agent（增量循环）"。背景为浅色，强调清晰的业务流程。

[视觉模块详解]
1. **左侧区域 - Initializer Agent**: 用浅蓝色(#DBEAFE)虚线框包裹，标题为"Initializer Agent（首轮奠基）"
   - 起点：蓝色胶囊形节点"空仓库"
   - 步骤依次向下：
     a. 蓝色矩形"分析输入规格"
     b. 蓝色矩形"生成 feature_list.json"，副文字"200+ 可验证功能点"
     c. 蓝色矩形"创建 init.sh"，副文字"可重复运行的环境脚本"
     d. 蓝色矩形"建立 claude-progress.txt"
     e. 蓝色矩形"初始 Git Commit"
   - 从最后一步引出粗箭头指向右侧区域

2. **右侧区域 - Coding Agent**: 用绿色(#D1FAE5)虚线框包裹，标题为"Coding Agent（增量循环）"
   - 形成一个循环结构：
     a. 绿色矩形"读取 feature_list.json"，副文字"选择最高优先级未完成项"
     b. 绿色矩形"查看 Git log + 进度文件"
     c. 绿色矩形"运行 init.sh 重启环境"
     d. 绿色矩形"实现一个功能"
     e. 红色菱形判断节点"E2E 测试通过？"
     f. 绿色分支（"是"）：绿色矩形"更新 passes 状态 + Git Commit"，然后回到 a 形成循环
     g. 红色分支（"否"）：红色矩形"修复 Bug"，回到 e

3. **关键约束标注**: 右下角用橙色标注框列出：
   - "每会话只处理一个功能"
   - "必须保持可合并状态"
   - "强制 E2E 测试验证"

[风格与配色方案]
白色背景，左侧区域偏蓝色调，右侧区域偏绿色调。循环用弧形箭头。判断节点用红/绿分支。配色参考"红绿灯"逻辑：正常流程蓝/绿，失败/重试红色。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
