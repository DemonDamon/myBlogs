[主题与布局设想]
展示 Claude-Mem 双数据库（SQLite + Chroma）的存储架构、双写策略与混合检索路径。采用中心对称的水平布局，左右两侧分别是 SQLite 和 Chroma 两个数据库，中间是 SearchManager 作为统一入口，上方是写入路径，下方是检索路径。背景干净纯白。图表标题为"双数据库存储与混合检索架构"。

[视觉模块详解]

Section A — 数据写入路径（上半部分）：
顶部中央有一个深紫色矩形节点，标注"AI Agent 输出：结构化观察记录"。
从这个节点向下引出一个菱形判断节点，标注"双写策略"。

菱形向左引出粗蓝色实线箭头，箭头上标注"① 同步写入（事务保证）"，指向左侧的 SQLite 圆柱体。
菱形向右引出细橙色虚线箭头，箭头上标注"② 异步写入（不阻塞主流程）"，指向右侧的 Chroma 圆柱体。

SQLite 圆柱体下方有一个小标注："失败 → 整体回滚"。
Chroma 圆柱体下方有一个小标注："失败 → 仅记日志，不影响主流程"。

Section B — SQLite 数据库（左侧）：
一个大的蓝色圆柱体图标，标注"SQLite"，副标注"~/.claude-mem/claude-mem.db"。
圆柱体内部列出关键表结构（小字）：
- "sessions 会话表"
- "observations 观察表"
- "session_summaries 摘要表"
- "user_prompts 用户提示表"
- "pending_messages 待处理队列"

圆柱体下方紧接一个蓝色小矩形，标注"FTS5 全文索引"，副标注"title · subtitle · narrative · facts"，旁边标注"BM25 相关度排序"。

Section C — Chroma 向量数据库（右侧）：
一个大的橙色圆柱体图标，标注"Chroma"，副标注"~/.claude-mem/chroma/"。
圆柱体内部列出存储内容（小字）：
- "向量嵌入（Embedding）"
- "doc_type 文档类型元数据"
- "project 项目元数据"
- "created_at_epoch 时间戳"

圆柱体下方紧接一个橙色小矩形，标注"语义相似度搜索"，旁边标注"余弦距离匹配"。

Section D — 混合检索路径（下半部分）：
中间有一个大的绿色菱形判断节点，标注"SearchManager\n查询路由"。
上方有一个查询入口箭头，标注"用户查询"。

菱形向左引出蓝色箭头，标注"纯元数据过滤\n（无查询文本时）"，指向 SQLite 圆柱体。
菱形向右引出橙色箭头，标注"语义搜索\n（有查询文本时）"，指向 Chroma 圆柱体。

从 Chroma 圆柱体向下引出一条橙色箭头，经过 3 个处理步骤（小矩形）：
- "top-100 语义候选"
- "90 天时效窗口过滤"
- "按 doc_type 分类"

最后从分类步骤引出箭头指向 SQLite 圆柱体，标注"从 SQLite 水合完整数据\n（保留语义排序）"。

底部中央有一个绿色矩形节点，标注"合并结果 → 返回给 Claude"。

降级路径：从 Chroma 圆柱体引出一条红色虚线箭头，标注"Chroma 不可用"，绕过语义搜索直接指向 SQLite 的 FTS5 节点，标注"降级为全文关键词检索"。

[风格与配色方案]
扁平化矢量风格。双色调对称配色方案：
- SQLite 侧：蓝色系（#2563EB / #DBEAFE）
- Chroma 侧：橙色系（#D97706 / #FEF3C7）
- SearchManager 和合并节点：绿色系（#059669 / #D1FAE5）
- 写入路径箭头：深灰色
- 降级路径：红色虚线（#DC2626）
圆柱体使用半透明渐变效果表示数据库。字体无衬线黑体。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
