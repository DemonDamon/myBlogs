[主题与布局设想]
展示 Claude-Mem 5 个生命周期钩子在一次完整编程会话中的触发时序与数据流向。采用从上到下的垂直时序流布局，左侧为 Claude Code 会话时间线，右侧为 Worker 服务的响应动作。背景干净纯白，通过时间线的纵向推进展示会话生命周期的完整过程。图表标题为"生命周期钩子触发时序与数据流"。

[视觉模块详解]

Section A — 时间线主轴（左侧）：
一条从上到下的灰色粗竖线作为时间轴，时间轴左侧标注"Claude Code 会话"。沿时间轴从上到下排列 5 个触发节点：

节点 1 — "SessionStart"（顶部）：
蓝色圆角矩形，内部文字"会话启动"。左侧有一个小人物图标标注"开发者打开 Claude Code"。
右侧引出蓝色实线箭头指向右方的响应区域，箭头上标注"GET /api/context/inject"。
响应区域是一个浅蓝色矩形框，内部写着"返回 Markdown 时间线\n（历史观察索引 + 类型图例）"。
下方有一个虚线反馈箭头返回时间轴，标注"静默注入 additionalContext"。

节点 2 — "UserPromptSubmit"（中上部）：
绿色圆角矩形，内部文字"用户提问"。左侧有一个对话气泡图标，写着"继续昨天的权限 Bug 修复"。
右侧引出绿色实线箭头，箭头上标注"POST 用户提示文本"。
响应区域是一个浅绿色矩形框，写着"记录提示 + 触发语义搜索\n注入 top-3 相关记忆"。

节点 3 — "PostToolUse"（中部，视觉最突出）：
深紫色圆角矩形，加粗边框，内部文字"工具调用完成"。左侧有一个齿轮图标，标注"例：WriteFile / ReadFile"。
右侧引出紫色粗实线箭头（最粗的箭头，表示核心数据流），箭头上标注"POST tool_name + tool_input + tool_response"。
响应区域是一个较大的浅紫色矩形框，内部有 3 行文字：
- "① 多级过滤（跳过列表 / 隐私检查）"
- "② AI Agent 压缩 → ~500 token 观察"
- "③ SQLite + Chroma 双写存储"
箭头下方有一个小标注框，写着"fire-and-forget，2s 超时\n（Endless Mode 下改为阻塞等待）"。
这个节点周围有一个虚线大括号，标注"会话中循环触发 N 次"。

节点 4 — "Stop"（中下部）：
橙色圆角矩形，内部文字"会话暂停"。
右侧引出橙色实线箭头，响应区域写着"触发会话总结生成"。

节点 5 — "SessionEnd"（底部）：
红色圆角矩形，内部文字"会话结束"。左侧有一个停止图标。
右侧引出红色实线箭头，响应区域写着"最终摘要持久化 + 清理"。

Section B — Worker 服务列（右侧）：
所有响应区域垂直排列在右侧，顶部标注"Worker 服务（端口 37777）"。各响应区域之间没有连接，表示独立处理。

底部标注区：
时间轴底部有一行小字："所有 Hook 均为轻量 HTTP 客户端（~75 行/个），不阻塞 IDE 响应"。

[风格与配色方案]
扁平化矢量风格，时序图配色。每个钩子节点使用不同颜色便于区分：
- SessionStart：蓝色（#3B82F6）
- UserPromptSubmit：绿色（#10B981）
- PostToolUse：紫色（#7C3AED），加粗突出
- Stop：橙色（#F59E0B）
- SessionEnd：红色（#EF4444）
时间轴为灰色（#6B7280），箭头跟随各节点颜色。右侧响应区域使用对应颜色的浅色版。字体无衬线黑体。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
