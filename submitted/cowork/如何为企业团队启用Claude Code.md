# How to enable Claude Code for your Enterprise team

> 来源：https://claude.com/resources/tutorials/how-to-enable-claude-code-for-your-enterprise-team
> 
> 了解如何为你的Claude企业计划添加Claude Code席位，以实现可靠的支出控制和配置。

- **分类**: Professional
- **阅读时间**: 5分钟

---

在整个组织中管理开发者工具不必意味着要处理多个平台和不可预测的成本。通过在你的Claude for Enterprise计划中使用Claude Code，你可以获得一个统一的控制中心，用于对话式AI和编码辅助——以及你作为管理员所需的内置支出控制。

在本指南中，我们将向你展示如何为你的Claude企业计划添加Claude Code席位。

## 开始使用席位分配

只有主要所有者和所有者可以管理席位分配。其他角色不会看到这些选项。

**访问席位管理：**

* 登录你的组织在 Claude.ai
* 点击左侧面板中的"Settings"（设置）
* 导航到"Members"（成员）
* 点击"View tier breakdown"（查看层级明细）以按层级查看可用席位

**席位层级概述：**

在成员中，你会注意到三种席位类型，每种都为你的用户提供独特的目的：

* **Standard席位** — Standard席位提供完整的Claude for Enterprise访问权限，但不包括Claude Code功能。将Standard席位分配给主要使用Claude进行写作、分析、研究和一般AI辅助的团队成员。这个层级非常适合项目经理、营销人员、内容创作者、业务分析师以及任何需要Claude的对话式AI但不经常编写代码的人。

* **Premium席位** — Premium席位包括Standard的所有内容，以及Claude Code访问权限和增加的Claude.ai和Claude Code使用限制。将Premium席位分配给需要AI辅助进行编码任务的开发者、工程师、数据科学家和技术团队成员。这些席位非常适合任何在Claude.ai中规划并在终端中实现之间切换的人，或需要更高使用限制以进行密集的AI辅助开发工作的人。

* **Unassigned席位** — Unassigned席位作为你的灵活性缓冲——它们是占位符分配，让你可以在Standard和Premium之间交换团队成员，而无需购买额外的席位。将这些视为你的储备池，用于处理团队变更、临时项目需求或试用期。

## 为成员分配席位

你有三种方式为团队成员分配Claude Code访问权限。每种方法在不同场景下效果最好，无论你是要入职单个开发者还是整个工程团队。

### 1. 单独添加成员

当你需要精确控制谁获得Claude Code访问权限，或者只是想测试这个流程时，单独分配效果很好。首先在"Members"（成员）部分点击"Add Member"（添加成员）。输入新成员的电子邮件地址并分配他们的角色和席位层级。选择Premium层级以授予Claude Code访问权限，或选择Standard层级以获取常规Claude访问权限（不包括Claude Code）。

### 2. 通过CSV批量添加成员

在入职多个团队成员时，批量添加可以节省大量时间。点击"Bulk add"（批量添加）并输入逗号分隔的电子邮件地址列表。选择这组成员的层级，然后点击"Add members"（添加成员）。请记住，每次批量上传只能分配一个层级。如果你需要同时分配Premium和Standard席位，请为每个层级组完成单独的上传。

### 3. 使用SCIM添加成员

启用SCIM的组织受益于新成员加入时的自动席位分配。你的身份提供商与Claude同步，成员根据层级可用性自动接收可用席位。主要所有者和所有者仍然可以在自动配置后手动调整层级分配。如果你用完了可用席位，溢出成员将收到"unassigned"（未分配）状态，直到席位可用。

## Claude Code最终用户体验

一旦席位被分配，Claude Code中的最终用户应该能够选择登录方法"Claude account with subscription"（带订阅的Claude账户），以将其使用指向你的企业计划。

**以下是一些你可以发送给用户的文案：**

"好消息！你现在可以通过我们的Enterprise计划访问Claude Code！要开始使用：

1. 访问Claude Code页面并为你的系统下载安装程序
2. 打开终端并输入 claude 启动
3. 🚨 当提示时选择'Claude account with subscription'（带订阅的Claude账户）
4. 在浏览器中选择我们的组织（以Claude.ai结尾）
5. 点击'Authorize'（授权）完成设置

如果你有个人Anthropic API账户，请确保选择我们的Enterprise组织，而不是你的个人账户。授权后返回终端，你就可以开始使用Claude Code进行开发工作了。"

## 一个企业计划，无限可能

Claude Code通过将Claude的对话智能与强大的编码能力相结合，改变了你的开发团队的工作方式。Premium席位持有者既获得增强的Claude使用限制，又获得完整的Claude Code访问权限，创建了统一的AI开发环境。你的开发者可以无缝地从在Claude.ai中讨论架构转向在终端中使用Claude Code实现解决方案。

这种集成方法意味着更快的原型设计、更高效的调试以及整个组织更好的代码质量。

此外，通过集中管理席位，你可以保持对访问和成本的控制，同时为你的团队提供他们需要的AI辅助以取得卓越成就。随着你的需求发展，你可以立即调整席位分配以匹配项目需求，确保合适的人在合适的时间拥有合适的工具。
