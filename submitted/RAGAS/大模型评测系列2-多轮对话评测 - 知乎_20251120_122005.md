## **一、多轮对话的核心评价维度**

### **1.1、上下文理解 (Context Awareness)**

+ **目标**：判断模型是否准确跟踪对话历史，正确引用上下文信息。
+ **示例测试**：

- 用户：*“巴黎是哪个国家的首都？” → 模型答：法国。*
- 用户（后续）：*“它的著名地标有哪些？” → 模型需正确关联“巴黎”并回答埃菲尔铁塔等。*

### **1.2、连贯性 (Coherence)**

+ **目标**：确保对话逻辑自然流畅，前后无矛盾。
+ **常见问题**：

- 话题跳跃不合理（如从“推荐餐厅”突然转向“量子力学”）。
- 人称/指代错误（如混淆对话中的多个实体）。

### **1.3、[任务完成度](https://zhida.zhihu.com/search?content_id=253850577&content_type=Article&match_order=1&q=%E4%BB%BB%E5%8A%A1%E5%AE%8C%E6%88%90%E5%BA%A6&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NjM3ODUxOTcsInEiOiLku7vliqHlrozmiJDluqYiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTM4NTA1NzcsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.-BMw5TAnlzEyC_Novsv5vLUpP9jVNavCGgORWluETg0&zhida_source=entity) (Task Completion)**

+ **目标**：针对任务型对话（如订票、客服），评估是否达成用户目标。
+ **指标**：关键信息提取准确率、流程步骤完整性。

### **1.4、长期一致性 (Long-term Consistency)**

+ **目标**：在长对话中保持事实、角色设定的一致性。
+ **测试案例**：

- 用户设定“你是一只猫”，后续对话中模型不应以人类身份回答。

### **1.5、[错误恢复能力](https://zhida.zhihu.com/search?content_id=253850577&content_type=Article&match_order=1&q=%E9%94%99%E8%AF%AF%E6%81%A2%E5%A4%8D%E8%83%BD%E5%8A%9B&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NjM3ODUxOTcsInEiOiLplJnor6_mgaLlpI3og73lipsiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTM4NTA1NzcsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.-NXcirXuS51hiBpiyNERsPrpacqF6EhuCCaHBGhLGnk&zhida_source=entity) (Error Recovery)**

+ **目标**：能否在用户输入模糊或错误时引导对话回到正轨。
+ **示例**：用户提问矛盾信息时，模型应主动澄清而非强行回答。

## **二、评价方法**

### **2.1、[自动评估](https://zhida.zhihu.com/search?content_id=253850577&content_type=Article&match_order=1&q=%E8%87%AA%E5%8A%A8%E8%AF%84%E4%BC%B0&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NjM3ODUxOTcsInEiOiLoh6rliqjor4TkvLAiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTM4NTA1NzcsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.YRXHJ7qSyRyRuCsGnzdkdRjwMuYjxE2FWK4rhT6YIcc&zhida_source=entity)（定量指标）**

* **基于规则的指标**：

+ **上下文匹配度**：使用检索模型（如BM25、BERT）计算当前回答与历史对话的相关性得分。
+ **指代消解准确率**：检测代词（如“它”、“他们”）是否指向正确实体。
+ **重复率**：统计模型重复生成相同内容的频率（高重复率可能表示逻辑断裂）。

* **基于模型的指标**：

+ **BERTScore**：用预训练模型（如BERT）对比生成回答与人工参考回答的语义相似度。
+ **DialoGPT 困惑度**：使用对话专用模型评估生成文本的自然程度。

* **任务型指标**：

+ **流程完成率**：预定任务（如订餐需包含时间、地点、菜品）的关键步骤覆盖比例。
+ **API调用准确率**：对需要外部接口调用的任务，验证参数正确性。

### **2.1.1、上下文匹配度 (Contextual Relevance)**

* **数学公式**：

使用检索模型计算当前回答 r\_i 与对话历史 H=\left\{q\_1,a\_1,...,q\_{i−1},a\_{i−1}\right\} 的相似度：

Score=\frac{1}{N}\sum\_{j=1}^{N}Similarity(r\_i,h\_j),h\_j∈H

其中 Similarity 可以是余弦相似度或 BM25 分值。

* **代码实现**（使用 Sentence-BERT 计算语义相似度）：

```
from sentence_transformers import SentenceTransformer
import numpy as np

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

def contextual_relevance(current_response, history, threshold=0.7):
    # 将历史对话拼接为字符串
    context = " ".join([f"{q} {a}" for q, a in history])
    # 编码文本
    resp_embedding = model.encode(current_response)
    context_embedding = model.encode(context)
    # 计算余弦相似度
    similarity = np.dot(resp_embedding, context_embedding) / (
        np.linalg.norm(resp_embedding) * np.linalg.norm(context_embedding)
    return similarity >= threshold  # 返回是否相关
```

### 2.1.2、**重复率 (Repetition Rate)**

* **数学公式**：

统计重复的 n-gram 比例（常用 n=4）： Repetition=\frac{重复的 n-gram 数量}{总 n-gram 数量}

* **代码实现**：

```
from collections import Counter

def repetition_rate(text, n=4):
    tokens = text.split()
    ngrams = [tuple(tokens[i:i+n]) for i in range(len(tokens)-n+1)]
    counts = Counter(ngrams)
    repeated = sum(1 for cnt in counts.values() if cnt > 1)
    return repeated / len(ngrams) if len(ngrams) > 0 else 0.0

# 示例
print(repetition_rate("你好你好，今天天气真好真好", n=2))  # 输出 0.5（重复2-gram："你好"和"真好"）
```

### 2.1.3、**BERTScore**

* **数学公式**：

基于预训练模型（如 BERT）的语义相似度计算 BERTScore=\frac{1}{∣r∣}\sum\_{w\_r∈r}max⁡\_{w\_{ref}∈ref}cosine(h\_{w\_r},h\_{w\_{ref}})

其中 *h* 是词向量，*r* 为生成文本，*ref* 为参考文本。

* **代码实现**（使用 `bert-score` 库）：

```
from bert_score import score

def bert_score_eval(candidates, references):
    # candidates: 生成文本列表
    # references: 参考文本列表
    P, R, F1 = score(candidates, references, lang="zh", verbose=True)
    return {"Precision": P.mean().item(), 
            "Recall": R.mean().item(), 
            "F1": F1.mean().item()}

# 示例
candidates = ["巴黎是法国的首都，有埃菲尔铁塔。"]
references = ["法国的首都是巴黎，著名地标包括埃菲尔铁塔。"]
print(bert_score_eval(candidates, references))  # 输出 F1 ~0.85
```

### 2.1.4、**困惑度 (Perplexity, PPL)**

* **数学公式**：

PPL=exp⁡(−\frac{1}{N}∑\_{i=1}^Nlog⁡P(w\_i∣w\_1,…,w\_{i−1}))

* **代码实现**（使用 HuggingFace Transformers）：

```
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

def calculate_ppl(text):
    inputs = tokenizer(text, return_tensors="pt")
    loss = model(input_ids=inputs["input_ids"], labels=inputs["input_ids"]).loss
    return torch.exp(loss).item()

# 示例
print(calculate_ppl("巴黎是法国的首都"))  # 输出类似 15.3
```

### 2.1.5、整合评估流程

```
class DialogueEvaluator:
    def __init__(self):
        self.context_model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
        self.ppl_model = AutoModelForCausalLM.from_pretrained("gpt2")
        self.ppl_tokenizer = AutoTokenizer.from_pretrained("gpt2")
        
    def evaluate(self, dialog_history, current_response, reference=None):
        metrics = {}
        # 上下文相关性
        context = " ".join([f"{q} {a}" for q, a in dialog_history])
        metrics["context_relevance"] = self._cosine_sim(current_response, context)
        # 重复率
        metrics["repetition"] = repetition_rate(current_response)
        # BERTScore（需提供参考回答）
        if reference:
            metrics["bertscore"] = bert_score_eval([current_response], [reference])["F1"]
        # 困惑度
        metrics["ppl"] = self._calculate_ppl(current_response)
        return metrics
    
    def _cosine_sim(self, text1, text2):
        emb1 = self.context_model.encode(text1)
        emb2 = self.context_model.encode(text2)
        return np.dot(emb1, emb2) / (np.linalg.norm(emb1)*np.linalg.norm(emb2))
    
    def _calculate_ppl(self, text):
        inputs = self.ppl_tokenizer(text, return_tensors="pt")
        loss = self.ppl_model(**inputs, labels=inputs["input_ids"]).loss
        return torch.exp(loss).item()

# 使用示例
evaluator = DialogueEvaluator()
history = [("你好", "你好！有什么可以帮您？"), ("巴黎的首都是哪里？", "巴黎是法国的首都。")]
current_response = "埃菲尔铁塔在那里。"
print(evaluator.evaluate(history, current_response, reference="埃菲尔铁塔位于巴黎。"))
```

  'repetition': 0.0,                # 无重复

### **2.2、[人工评估](https://zhida.zhihu.com/search?content_id=253850577&content_type=Article&match_order=1&q=%E4%BA%BA%E5%B7%A5%E8%AF%84%E4%BC%B0&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3NjM3ODUxOTcsInEiOiLkurrlt6Xor4TkvLAiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNTM4NTA1NzcsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.dVHd1y-a1TqKkf2XKeKTTlcscKS7MBgVzv7HA7Scv1c&zhida_source=entity)（定性分析）**

* **评分维度**（通常采用1-5分制）：

| 维度 | 描述 |
| --- | --- |
| 相关性 | 回答是否与当前对话阶段相关 |
| 信息准确性 | 内容是否事实正确、无幻觉 |
| 逻辑连贯性 | 上下文过渡是否自然 |
| 用户友好性 | 是否简洁易懂、语气恰当 |
| 主动性 | 能否主动澄清需求或提供扩展信息 |

* **评估流程**：

1. **设计多样化对话场景**（涵盖开放闲聊、任务导向、知识问答等）。
2. **招募标注人员**（需明确标注指南，如“角色扮演场景中不允许打破设定”）。
3. **交叉验证**：同一对话由多人评分，计算Kappa系数确保一致性。

* **攻击类型**：

+ **话题突变**：突然切换无关主题，测试模型是否强行关联或合理拒绝。
+ **信息干扰**：在对话历史中插入矛盾信息（如“我喜欢苹果，但讨厌水果”）。
+ **长程依赖**：相隔多轮后提及早期信息（如第10轮追问第2轮的细节）。

## **三、评估流程设计**

### **数据准备阶段**：

+ **构建测试集**：

- 真实用户对话日志（需去敏感信息）。
- 人工构造边缘案例（如多实体指代、隐含意图）。

+ **定义评估标准**：明确各指标权重（如任务型对话侧重完成度，闲聊侧重连贯性）。

### **多轮交互测试执行**：

+ **工具支持**：使用自动化框架（如DialoFlow、Rasa）模拟多轮对话。
+ **动态上下文注入**：在对话中随机插入干扰轮次，测试模型抗干扰能力。

### **结果分析与迭代**：

+ **错误模式分类**：将失败案例归类（如指代错误、事实错误、逻辑断裂）。
+ **针对性优化**：根据错误类型调整训练数据或添加规则约束。
+ **A/B测试**：对比新旧版本在相同测试集上的表现。
