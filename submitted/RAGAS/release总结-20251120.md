# Ragas 最近三次 Release 总结 (v0.3.7 - v0.3.9)

根据最新的 Release Note，以下是 Ragas 最近三个版本（v0.3.7 至 v0.3.9）的主要更新特点总结：

## v0.3.9 (Latest)
**核心特点：指标全面迁移与文档重构**

*   **指标体系大规模迁移**: 大量核心评估指标完成了迁移工作，包括 `SummaryScore`、`Faithfulness`（忠实度）、`Context Precision`（上下文精度）、`Factual Correctness`（事实正确性）、`Response Groundedness`（回答依据性）以及 `Context Recall`（上下文召回率）。
*   **文档体验升级**:
    *   推出了带有交互式 LLM 设置和项目结构的**快速入门指南**。
    *   文档结构调整为以**实验优先 (experiments-first)** 的范式。
    *   新增了 `metrics.collections` API 的详细文档。
*   **功能增强**:
    *   为合成数据 (synthetic data) 添加了元数据字段，增强了**可追溯性**。
    *   在 `AnswerCorrectness` 中支持纯事实模式 (pure factuality mode)，使得 embeddings 变为可选。
    *   修复了较新 OpenAI 模型的 `max_completion_tokens` 错误处理。

## v0.3.8
**核心特点：CLI 工具增强与新指标引入**

*   **易用性提升**:
    *   新增 `quickstart` 命令行工具及运行模板，简化上手流程。
    *   为 `ragas_examples` 添加了控制台脚本支持。
*   **新指标**: 引入了 **Aspect Critic metric**，支持对一致性 (coherence)、有害性 (harmfulness)、恶意性 (maliciousness) 和正确性 (correctness) 进行评估。
*   **基础设施**: 添加了用于指标迁移的可复用测试基础设施。
*   **指标迁移**: 完成了 `Semantic Similarity`、`Answer Correctness` 和 `Context Entity Recall` 等指标的迁移。

## v0.3.7
**核心特点：代码质量改进与字符串指标迁移**

*   **代码重构**: 重点提升了指标 (metrics) 的代码质量，并移除了旧版的分析模块。
*   **指标迁移**: 将传统的字符串指标（如 `Rouge`、`Bleu`）以及 `Answer Relevance`（回答相关性）、`Answer Similarity` 迁移到了 collections 中。
*   **文档改进**: 简化了早期的操作指南，重组了 Prompt 评估导航，并新增了关于对齐 LLM-as-Judge 的指南。
*   **功能修复**: 修复了多跳特定查询合成中的主题提取问题，增强了查询分布的鲁棒性。
