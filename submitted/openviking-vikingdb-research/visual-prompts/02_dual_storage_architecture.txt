[主题与布局设想]
主题：OpenViking 双存储架构设计图
布局设想：采用水平分栏布局，左侧展示 URI 抽象层，右侧分为上下两部分展示内容存储层和索引存储层。用水平箭头表示依赖关系。

[视觉模块详解]
模块1（左侧）：
- 标题：VikingFS（URI 抽象层）
- 功能：统一的 URI 映射、文件操作、关系管理
- 形状：矩形，使用紫色填充
- 位置：左侧居中
- 功能列表（模块内部）：
  • URI 解析
  • 文件系统操作（list/find/glob）
  • 上下文关系管理

模块2（右上部）：
- 标题：AGFS（内容存储）
- 存储内容列表：
  • L0/L1/L2 分层文件
  • 多媒体资源
  • 关系 JSON 数据
- 形状：圆角矩形，使用蓝色填充
- 位置：右侧上部
- 箭头：从 VikingFS 指向 AGFS

模块3（右下部）：
- 标题：VectorDB（索引存储）
- 索引内容列表：
  • URI 索引
  • Dense 向量索引
  • Sparse 向量索引
  • 标量元数据
- 形状：圆角矩形，使用绿色填充
- 位置：右侧下部
- 箭头：从 VikingFS 指向 VectorDB

底部说明区：
- 标题：存储分离优势
- 优势列表：
  ✓ 性能优化：专注索引检索 vs 内容存储
  ✓ 数据一致性：通过 URI 关联同步
  ✓ 扩展性：独立扩展存储层和索引层
  ✓ 容错性：单层故障不影响整体

[风格与配色方案]
设计风格：技术系统架构图风格，扁平化设计
配色方案：
- VikingFS（抽象层）：紫色（#C4B5FD）
- AGFS（内容存储）：蓝色（#4D9FFF）
- VectorDB（索引存储）：绿色（#52C41A）
- 文字：深灰色（#333333）
- 连线：深灰色（#666666）
- 优势标记：绿色（#4CAF50）

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
