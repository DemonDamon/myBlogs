[主题与布局设想]
主题：OpenViking 与 VikingDB 上下层架构关系图
布局设想：采用垂直分层布局，从上到下清晰展示三层架构结构。顶部是应用层，中间是服务层，底部是存储层。使用颜色区分不同层级，用箭头表示数据流向。

[视觉模块详解]
模块1（顶部）：
- 标题：应用层（Application Layer）
- 内容：AI Agent 应用
- 形状：圆角矩形，使用蓝色填充
- 位置：顶部居中

模块2（中部上层）：
- 标题：服务层（Service Layer）
- 内容：OpenViking - Agent 专用上下文数据库
- 关键特性列表：
  1. 文件系统范式
  2. 三层上下文（L0/L1/L2）
  3. 记忆/资源/技能管理
- 形状：矩形，使用绿色填充
- 位置：中部，偏左
- 箭头：从 AI Agent 指向 OpenViking

模块3（中部下层）：
- 标题：存储层（Storage Layer）
- 内容：VikingDB - 向量数据库
- 关键特性列表：
  1. 多模态数据检索
  2. 向量索引（Dense + Sparse）
  3. 标量/主键过滤
- 形状：矩形，使用橙色填充
- 位置：中部，偏右
- 箭头：从 OpenViking 指向 VikingDB，标注 "viking:// 协议"

模块4（底部）：
- 标题：数据持久层
- 内容：AGFS（本地/云文件系统） + LocalCollection / 云端索引
- 形状：圆柱形，使用灰色填充
- 位置：底部居中
- 箭头：从 VikingDB 指向数据持久层

右侧说明区域：
- 标题：架构说明
- 要点列表：
  • OpenViking 使用 viking:// 协议管理上下文
  • VikingDB 提供高性能向量索引
  • 两者通过 URI 关联协作
  • 支持本地（flat）和云端（hnsw）两种索引模式

[风格与配色方案]
设计风格：现代技术架构图风格，扁平化设计
配色方案：
- 应用层：浅蓝色 (#E3F2FD)
- OpenViking：浅绿色 (#D1F2EB)
- VikingDB：浅橙色 (#FFE0B2)
- 存储：浅灰色 (#E0E0E0)
- 文字：深灰色 (#333333)
连线颜色：深灰色 (#666666)

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
