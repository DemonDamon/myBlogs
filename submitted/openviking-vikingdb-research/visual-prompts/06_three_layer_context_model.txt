[主题与布局设想]
主题：OpenViking 三层分层上下文模型（L0/L1/L2）设计图
布局设想：采用水平对比布局，将三个层级（L0、L1、L2）并排展示，每个层级用独立的卡片展示。使用渐变颜色或不同深浅色调区分层级，底部添加应用场景说明。

[视觉模块详解]
标题区：
- 主标题：OpenViking 三层分层上下文模型
- 副标题：按需加载机制优化 Token 消耗

L0 层卡片（左侧）：
- 标题：L0 - Abstract（摘要层）
- Token 限制：~100 tokens
- 目的：向量搜索，快速过滤
- Agent 感知度："知道有这个东西"
- 应用场景：初步筛选、快速匹配
- 形状：圆角矩形，使用浅蓝色填充
- 图标：🔍（搜索图标）
- 位置：左侧

L1 层卡片（中间）：
- 标题：L1 - Overview（概述层）
- Token 限制：~2000 tokens
- 目的：重排序，内容导航
- Agent 感知度："理解大致内容与位置"
- 应用场景：决策规划、任务分解
- 形状：圆角矩形，使用中蓝色填充
- 图标：📋（文档图标）
- 位置：中间

L2 层卡片（右侧）：
- 标题：L2 - Detail（详情层）
- Token 限制：无限制
- 目的：完整原始数据，按需加载
- Agent 感知度："获取精准细节并执行"
- 应用场景：深度分析、具体执行
- 形状：圆角矩形，使用深蓝色填充
- 图标：📄（代码图标）
- 位置：右侧

底部流程说明：
- 标题：分层加载流程
- 流程描述：
  1. Agent 请求上下文
  2. 系统优先加载 L0 进行快速筛选
  3. 确认相关后加载 L1 进行内容导航
  4. 需要时按需加载 L2 获取完整细节

右侧优势总结：
- 标题：Token 优化优势
- 优势列表：
  ✓ 避免浪费：不加载无关的 L2 详情数据
  ✓ 快速响应：L0 提供快速匹配能力
  ✓ 按需扩展：根据任务需求动态加载层级
  ✓ 推理效率：Agent 可根据场景选择合适粒度

[风格与配色方案]
设计风格：系统架构分层图风格，扁平化设计
配色方案：
- L0 层：浅蓝色（#BBDEFB）
- L1 层：中蓝色（#6495ED）
- L2 层：深蓝色（#1565C0）
- 卡片背景：白色（#FFFFFF）
- 文字颜色：深灰色（#333333）
- 边框：浅灰色（#E0E0E0）
- 连线：虚线（#90CAF9）
- 标记符号：绿色（#4CAF50）

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
