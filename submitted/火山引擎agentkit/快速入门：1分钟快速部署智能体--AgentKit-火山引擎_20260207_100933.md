问问助手

本文以基于[VeADK](https://volcengine.github.io/veadk-python/agent/agent/)类型的Agent镜像为例介绍从创建到使用运行时的全流程，帮助您快速上手AgentKit。​

前提条件​

* 请确认已完成[账号注册](https://www.volcengine.com/docs/6261/64925)和[实名认证](https://www.volcengine.com/docs/6261/64935)。​

* 已开通AgentKit服务。若未开通，请登录[AgentKit控制台](https://console.volcengine.com/AgentKit)，根据系统引导开通产品。​

首次登录AgentKit服务控制台，平台将默认勾选使用AgentKit基础功能的必备依赖产品（包含函数服务、API网关、镜像仓库等），您也可以根据实际业务需求，勾选所需的其他产品，然后单击“批量开通并授权”按钮确认“AgentKit依赖服务开通及跨服务授权”，允许AgentKit服务使用已选择的产品。​

​![](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_87c284ee59c1af4cf749d2f322d4400e.jpg)​​

* 已[开通火山方舟模型服务](https://console.volcengine.com/ark/openManagement)。​

步骤一：创建智能体运行时​

* 除通过控制台创建智能体运行时外，您还可以使用AgentKit CLI工具将本地代码部署到云上AgentKit智能体运行时，具体操作，请参见[通过CLI工具创建运行时](https://www.volcengine.com/docs/86681/1844871)。​

* AgentKit提供了基于场景化的模板Agent，您可以前往“概览”页单击“快速开始”选择模板快速部署并体验，关于各模板的介绍，请参见[应用概述](https://www.volcengine.com/docs/86681/1996368)。​

1. 登录[AgentKit 控制台](https://console.volcengine.com/agentkit)。​

2. 在左侧导航树中，选择“智能体运行时”。​

3. 单击“创建智能体”，配置智能体运行时信息，未提及的参数则保持默认配置。​

说明​

更多参数介绍，请参见[创建智能体运行时](https://www.volcengine.com/docs/86681/1844831)。​

* ​

  |  |  |
  | --- | --- |
  | 参数​ | 说明​ |
  | 名称​ | 自定义智能体运行时名称。例如，agentkit-runtime。​ |
  | 镜像​ | 选择“公共镜像”下的“财务分析智能体”。​ |
  | 网络访问​ | 选择“公网访问”。​ |
  | IAM角色​ | 选择“新建角色”，平台将自动赋予访问火山其他云服务资源的权限。​ |
  | 入站身份认证​ | 选择“API Key”访问智能体运行时托管资源。​ |
  | 观测服务​ | 选择“启用”观测服务。​ |
  | 模型选择​ | 使用默认模型“doubao-seed-1-6”。​ |
  | 所属项目​ | 选择“default（默认项目）”。​ |

  ​

4. 勾选“产品处于公测/邀测阶段，我已阅读同意[《产品和服务测试协议》](https://www.volcengine.com/docs/6256/79748)”，然后单击“创建”，完成操作。​

步骤二：调试Agent​

1. 单击刚创建的智能体运行时操作列的“在线测试”按钮，在Agent在线测试面板，指定域名发起 POST 请求，以此验证Agent是否正常工作。本示例参数保持默认配置。详细参数说明，请参见[调用Agent](https://www.volcengine.com/docs/86681/2167966)。​

说明​

域名会自动填充为本智能体的域名。​

* ​![](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_4333d772becc94078048279c3351d508.png)​​

2. 查看调试结果。​

* ​![](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_20682e2d862077a128caa23849dcc303.png)​​

步骤三：观测智能体​

调试成功后，您可以在“数据观测”页面查看Agent的运行时监控、会话分析、Trace分析、模型监控、日志分析。详情请参见[观测概览](https://www.volcengine.com/docs/86681/2117509)。​
