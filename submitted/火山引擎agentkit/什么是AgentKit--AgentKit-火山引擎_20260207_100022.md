什么是AgentKit

文档反馈

问问助手

AgentKit是火山引擎为AI Agent构建、部署、运行提供支持的开发工具平台，帮助开发者和企业降低Agent开发门槛，为Agent提供模型之外的安全、内置工具、记忆、知识、监控、评测等基础设施，助力企业高效构建、部署、运维复杂智能的企业级Agent。​

产品架构​

​![](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_6a6119e1953b4166cc01e24bcedc79ca.jpg)​​

产品能力​

* 提供丰富的产品组件，提供安全、便捷的一站式Agent基础设施​

* ​

  |  |  |
  | --- | --- |
  | 产品组件​ | 说明​ |
  | 智能体运行时​ | 负责高效、安全地管理AI Agent运行、会话和资源调度，为AI Agent提供安全隔离的托管式运行环境，支持便捷且规模化的部署。​ |
  | Skill​ | Skill是一种可完成特定任务的模块化能力单元，通过将Skill注入Skills空间并集成到不同智能体中，可快速赋予智能体对应能力，适配各类业务场景。​ |
  | 工具​ | 提供了多种Agent在执行任务中需要的运行环境工具和模块化能力包，支持快速集成与便捷调用。​ |
  | 记忆库​ | 提供企业级的长期记忆管理能力。通过统一接口对接主流记忆库框架（mem0记忆库、Viking记忆库等），帮助Agent实现跨会话的上下文感知、个性化交互和持续学习与演进。​ |
  | 知识库​ | 提供主流的知识库的一键配置导入能力，实现在AgentKit平台轻松关联知识库，并提供统一的知识库接口与框架对接，提升Agent使用不同知识库的便利性。​ |
  | 网关​ | 提供统一的接口网关，负责Agent与外部系统、服务的连接与数据交互，为MCP服务提供安全可靠的访问入口；提供API到MCP的快速转换能力，加速存量系统与大模型的对接；同时提供基于语义搜索自动匹配最相关的工具的能力。​ |
  | 身份与权限​ | 负责用户身份验证、权限控制和访问管理，确保Agent出、入操作的安全性与合规性。​ |
  | 观测​ | + 提供全链路的应用观测能力，实现对AgentKit平台的实时监控、日志记录、性能指标收集，并提供异常检测与报警，为Agent的调优和稳定性维护提供基础支撑。​  + 提供面向记忆库、MCP服务的基础监控能力，通过多维度指标与可视化面板实时呈现组件状态。​ |
  | 评测​ | 提供在线实时监控评测能力和离线评测能力（eval），建立完善的在线评测体系，确保Agent服务质量和稳定性，持续优化效果，及时响应用户需求变化，最大化业务价值。​ |
  | 日志​ | 提供日志持久化存储能力，部署在AgentKit的资源只需要开启观测服务，即可实现日志投递与查看。​ |

  ​

* 支持多种框架和构建、部署方式​

* 支持[VeADK](https://volcengine.github.io/veadk-python/veadk/)原生Agent构建，VeADK构建的Agent可以无缝对接AgentKit并充分发挥Agent高阶能力。​

* 提供AgentKit SDK装饰器改造方案，基于主流Python框架构建的Agent可以通过简单适配代码与AgentKit快速对接。​

* 支持本地代码包和容器镜像等不同部署方式。​

* 支持HTTP server、A2A、MCP主流协议，满足多种接入场景。​

* 采用Serverless服务方式，全面降低开发、运维、资源成本​

* Serverless托管模式，用户免运维，减少开发、运维过程中对复杂环境依赖的配置工作，大幅度降低人力成本。​

* 按量计费，根据线上实际流量进行资源的扩、缩容，动态调整计算资源，避免了高峰期过度资源配置和低峰期资源浪费的问题，从而优化了整体资源的成本效率。​
