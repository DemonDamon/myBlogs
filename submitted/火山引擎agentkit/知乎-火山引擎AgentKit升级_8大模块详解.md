## 概述

12月18日，火山引擎宣布**全面升级企业级 AI Agent 平台 AgentKit**。

AgentKit 是火山引擎为 Agent 构建、部署、运行提供支持的平台，提供**安全、运行时、沙箱工具、网关、记忆、监控、评测、安全护栏**八大核心模块能力，助力企业高效构建、部署、运维复杂Agent，快速实现智能化转型。

## 八大核心模块

### 1. Identity - 统一身份与权限管理

为每一个 Agent 提供清晰、可审计的身份标识，明确其任务执行范围与工具调用权限，从源头规避权限滥用风险。

**核心特性：**
- **最小权限+细粒度授权**：仅为 Agent 分配执行任务必需的权限
- **OAuth 2.0 支持**：支持 2LO 与 3LO 灵活授权模型
- **链式权限授权&鉴权**：全链路权限可追溯，让每一次任务执行都"有据可查、有权可依"

### 2. Runtime - 企业级全托管零信任运行环境

让 Agent 不再跑在脚本和 Demo 里，而是运行在稳定、弹性、可隔离的生产环境中。

**核心特性：**
- **全托管运行环境**：无需单独配置计算、网络、存储依赖以及安全策略
- **自动扩缩容**：根据请求并发度和计算负载自动扩缩容实例
- **主流框架支持**：支持托管任何主流 python 框架开发的 Agent
- **装饰器改造**：以装饰器的简单改造方式，即可轻松做镜像构建和部署

### 3. Sandbox - Skills 运行的安全载体

基于用户会话分钟内智能调度万级别实例安全代码沙箱，实现极速启动、原生安全设计、内置身份控制等能力。

**核心特性：**
- 将所有可能修改系统环境、访问敏感数据或执行不可信代码的调用都集成在沙箱中运行
- **All-In-One 多端支持**：code、browser、Computer-user-agent（CUA）、Mobile-use-agent（MUA）等

### 4. Gateway - 智能体网关加速存量应用智能化

无论是人、系统还是 Agent，访问路径、鉴权、策略都在这里统一收敛。

**核心特性：**
- **HTTP 服务自动转化**：支持通过 API 定义将企业存量 HTTP 服务自动转化为 MCP 服务，实现零代码改造
- **MCP 服务部署**：快速部署开源 MCP 服务和自建 MCP 服务
- **认证鉴权**：对访问 MCP Server 的请求进行认证鉴权
- **语义匹配**：通过对 Agent 工具调用的意图与 MCP tool 描述进行语义匹配，提高 tool 匹配的准确度

### 5. Memory - 用户级隔离的长期记忆

为 Agent 提供记忆体系功能，让 Agent 具备长期、可管理、可治理的上下文记忆。

**核心特性：**
- **豆包大模型加持**：在 LOCOMO 基准测试中，豆包大模型以 90.12% 准确率排名第一
- **多模态记忆支持**
- **高性能**：毫秒级召回十亿级记忆条目，秒级索引更新，单库支持超 4 亿条目
- **双引擎支持**：搭载火山自研 viking 记忆库、mem0 开源记忆库双引擎

### 6. Evaluation - Agent 评测与自反馈

实现智能体实时效果监控和白盒化评估，助力企业对 Agent 进行效果评估、持续迭代。

**核心特性：**
- **字节内部同款**：源自豆包、Seed 等字节跳动 2000+ 内部团队的同款评测平台
- **海量数据积累**：累计对 1 万+ Agent 完成了 20 万+次评测，沉淀 3000 万+ 优质评测数据
- **双轨评测模式**：离线+在线，上线前严格把关，上线后实时监控
- **双维度评测**：过程+结果，全程记录决策链路
- **50+ 官方评估器**：高效评估内容质量、工具调用效果、轨迹质量等核心维度

### 7. Observation - 全链路可观测

为 Agent 建立完整的链路可追溯能力，解决智能体黑盒困境。

**核心特性：**
- **一条 trace+一个看板大盘**：端到端全景全栈分析
- **Token 消耗追踪**：精准追踪和分析每次交互的 Token 消耗，实时异常消耗预警
- **多框架兼容**：全面兼容主流 AI 应用开发框架，通过标准化埋点与自动注入技术实现数据采集

### 8. Guardrails - Agent 安全围栏

提供前置/后置一体化安全与审计，防护算力级 DDoS、提示词注入、敏感数据泄露及模型滥用。

**核心特性：**
- **合规认证**：满足 TC260 内容安全合规要求，覆盖 OWASP LLM TOP 10 风险项
- **灵活接入**：支持 SDK 嵌入、网关拦截等灵活的接入部署方式
- **自定义策略**：支持自定义话题控制、敏感词库、业务场景等检测
- **高性能**：提示词注入误报率 <0.01%，端到端检测延迟 <150ms

## 实战案例：智能会议助手

基于 AgentKit 打造的智能会议助手，包括：
- 智能推荐 Agent
- 智能签到 Agent
- 智能总结 Agent

### 效果对比

| 指标 | 传统开发 | AgentKit 开发 |
|------|----------|---------------|
| 代码量 | ~2000 行 | ~70 行 |
| 减少比例 | - | **96%** |

### 四大优势体现

1. **安全可信**：一行代码实现权限可追溯，原生融入火山企业身份体系
2. **存量焕新**：将原有业务接口直接转化为 MCP Server，实现快速桥接
3. **智能跃升**：两行代码集成 Memory，生成"因人而异"的专属总结报告
4. **质量可见**：50+ 标准化评估器，让 Agent 效果质量可量化、可对比
5. **快速投产**：一行命令部署到 Runtime，实例启动时间 <150ms
