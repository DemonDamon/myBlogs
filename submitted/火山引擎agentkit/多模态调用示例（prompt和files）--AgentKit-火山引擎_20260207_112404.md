多模态调用示例（prompt和files）

文档反馈

问问助手

本文介绍Agent多模态调用方法，实现将图片、视频、PDF等多模态文件直接作为AgentKit模型输入，让模型直接解析多模态内容，无需借助外部工具分析（例如，输入URL到Prompt中依赖文件解析工具分析）。​

环境准备​

1. Python环境初始化。​

* 使用uv构建独立的Python虚拟环境（推荐Python 3.10+）。​

* ​

  Bash

  复制

  # 初始化 uv 配置​

  uv init​

  # 创建 uv 虚拟环境​

  uv venv​

  ​

2. 安装依赖包。​

1. 安装最新版本的VeADK。​

* ​

  Bash

  复制

  uv pip install "git+https://github.com/volcengine/veadk-python.git"​

  ​

2. 安装AgentKit SDK。​

* ​

  Bash

  复制

  uv pip install agentkit-sdk-python​

  ​

3. 开启多模态文件上传能力。​

* 在agent代码中添加enable\_responses=True，enable\_responses参数开启后会兼容Response API从而打开图片视频和PDF的文件上传能力。​

* ​

  Bash

  复制

  agent = Agent(​

  name=agent\_name,​

  description=description,​

  instruction=system\_prompt,​

  tools=tools,​

  enable\_responses=True # 开启多模态文件输入能力​

  )​

  ​

多模态文件调用测试​

修改完成后，可通过curl命令调用/invoke接口，传入prompt（文本指令）和files（多模态文件URL列表），以下是不同文件类型的调用示例：​

图片文件调用​

​

Bash

复制

curl --location 'http://127.0.0.1:8000/invoke' \​

--header 'Content-Type: application/json' \​

--header 'user\_id: 123' \​

--header 'session\_id: 1234243' \​

--data '{​

"prompt": "describe this image , without using any tool",​

"files": ["your image url"]​

}'​

​
