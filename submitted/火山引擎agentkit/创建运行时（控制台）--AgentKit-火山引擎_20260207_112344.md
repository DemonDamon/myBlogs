文档反馈

问问助手

本文为您介绍如何创建智能体运行时，定义智能体的部署方式、访问模式、权限与访问控制等。​

前提条件​

* 已开通AgentKit服务。若未开通，请登录[AgentKit控制台](https://console.volcengine.com/AgentKit)，根据系统引导开通产品。​

* （可选）如需使用火山引擎方舟模型服务提供的预置模型，请确认已[开通火山方舟模型服务](https://console.volcengine.com/ark/openManagement)。​

* （可选）如需使用自定义Agent，请确认已上传Agent镜像到火山引擎镜像仓库（CR）中。详细操作，请参见[基于Docker推送和拉取镜像](https://www.volcengine.com/docs/6420/68645)。​

* （可选）如需通过私有网络VPC访问智能体运行时，请确保已开通火山引擎私有网络，并已在智能体运行时待部署地域创建私有网络、子网。详细操作请参见[创建私有网络](https://www.volcengine.com/docs/6401/69467)、[创建子网](https://www.volcengine.com/docs/6401/67823)。​

* （可选）如需观测运行时的运行时监控、运行时日志等，请确认已[开通全栈可观测平台](https://console.volcengine.com/observe/apmplus-server/region:apmplus-server+cn-beijing/console/overview/server?projectName=default)。​

操作步骤​

除控制台创建外，AgentKit还支持通过CLI工具将本地Agent代码部署到运行时，详细操作请参见[通过CLI工具创建运行时](https://www.volcengine.com/docs/86681/1844871)。​

1. 登录[AgentKit控制台](https://console.volcengine.com/agentkit)。​

2. 在左侧导航树中，选择“智能体运行时”。​

3. 单击“创建智能体”，在创建页面参照下表完成参数配置。​

* 基础配置​

* ​

  |  |  |  |
  | --- | --- | --- |
  | 参数​ | 说明​ | 示例​ |
  | 名称​ | 自定义智能体运行时名称。同一账号下智能体运行时名称不可重复，创建后不支持修改。​ | agentkit\_runtime​ |
  | 镜像​ | 支持自定义镜像和公共镜像。​  + 自定义镜像：支持从镜像仓库选择或者输入火山镜像地址。​  + 公共镜像：AgentKit平台预置的开箱即用的镜像。当前仅支持财务分析智能体。​ | 公共镜像：财务分析智能体​ |
  | 最小实例数​ | 配置承载Agent运行的计算资源最小实例数。设置后，无论是否存在请求负载，平台均会持续保留该数量的实例并按此计费。​  + 取值：0～最大实例数。​  + 默认值为 1。​  设置为1，可有效减少实例冷启动（即实例从无资源分配状态下，从零加载运行环境、初始化依赖组件，直至完成全量初始化并被触发启动的全过程）耗时。​ | 1​ |
  | 最大实例数​ | 智能体运行时实例配额上限。​  + 取值：1～10。如需提升最大实例数上限，请前往[配额中心](https://console.volcengine.com/quota/productList/ParameterList?ProviderCode=agentkit)[配额中心](https://console.byteplus.com/quota/productList/ParameterList?ProviderCode=ecs)申请提升runtime/instances配额上限。​  + 默认值为10。​ | 10​ |

  ​

* 网络配置​

* ​

  |  |  |  |
  | --- | --- | --- |
  | 参数​ | 说明​ | 示例​ |
  | 网络访问​ | 配置访问智能体运行时的网络访问方式，包括：​  + 公网访问：默认访问方式。​  + 私网访问：选择同地域中的任意一个VPC和子网，每个可用区支持最多选择一个子网。​ | --​ |
  | 共享公网访问​ | 运行时公网出口配置。仅当网络访问选择私网访问时，支持开启共享公网端口。​  开启共享公网出口后，运行时将使用平台提供的公网出口访问公网。未开启，将默认使用您私有网络中已配置的公网出口访问公网。​ | --​ |

  ​

* 权限与访问控制​

* ​

  |  |  |  |
  | --- | --- | --- |
