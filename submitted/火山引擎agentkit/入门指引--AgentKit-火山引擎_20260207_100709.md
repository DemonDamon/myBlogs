本文介绍如何使用VeADK、AgentKit CLI、AgentKit平台，从开发、部署到管理智能体的全流程。​

AgentKit与VeADK关系​

AgentKit是整合VeADK及火山引擎生态能力的企业级AI Agent平台，通过可视化控制台、AgentKit CLI工具等基础设施，降低Agent开发、部署与运维门槛，同时支持第三方框架Agent接入；而VeADK作为Agent开发工具，提供完整的能力抽象与开发框架。二者协同互补，VeADK作为Agent开发工具，通过模块化的能力集成，便捷化客户的智能体开发，AgentKit平台聚焦于便捷的操作体验以及部署与运维能力，两者协同配合，覆盖Agent从开发、调试到部署与运维的全生命周期需求。​

构建和部署智能体工作流​

从开发、部署及管理智能体的流程如下图所示。推荐使用[VeADK](https://agentkit.gitbook.io/docs)开发框架构建智能体。​

​![](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ffe15b50fac372d9d77b725fd0f60e66.jpg)​​

1. 确定智能体的大模型、组件（工具、记忆库、知识库等）并使用VeADK或其他主流智能体开发框架构建智能体。​

2. 使用AgentKit CLI工具将智能体部署到AgentKit。​

3. 使用AgentKit在线测试功能或AgentKit CLI工具测试Agent。​

4. 在AgentKit中管理Agent。​

部署模式​

AgentKit CLI支持灵活的部署模式，旨在适应从开发到生产的不同阶段。​

​

|  |  |  |
| --- | --- | --- |
| 部署模式​ | 核心优势​ | 适用场景​ |
| 本地模式 (Local)​ | 迭代速度快，支持离线工作，便于直接调试。​ | 适合快速开发和调试。​ |
| 云端模式 (Cloud)​ | 无需本地Docker环境，使用云上持续交付产品全云端部署，内置可观测性，环境一致性高，安全可靠。​ | 适合生产环境。​ |
| 混合模式 (Hybrid)​ | 兼顾本地构建的灵活性和云端运行环境的稳定性。​ | 适合开发调试阶段，本地快速构建镜像后推送到云端运行。​ |
