| 分类​ | 功能​ | 说明​ | 相关文档​ |
| 智能体运行时​ | 智能体运行时​ | 一个智能体运行时等于一个Agent，只需指定容器镜像，并配置所需要的安全访问等设置，即可将Agent托管至运行时，并自动为您创建访问链接。​ | [运行时概述](https://www.volcengine.com/docs/86681/1844854)​ |
| 工具​ | 工具实例​ | 提供了多种Agent在执行任务中需要的运行环境工具和模块化能力包，支持快速集成与便捷调用。您可根据业务需求创建预置工具或自定义工具。​ | [工具概述](https://www.volcengine.com/docs/86681/1847933)​ |
| ​ | 工具实例生命周期管理​ | 一个Session对应一个单独的实例，支持手动创建和销毁或创建时指定超时时间触发自动回收。​ | * [创建工具实例](https://www.volcengine.com/docs/86681/1860266)​  * [修改工具实例生命周期时长](https://www.volcengine.com/docs/86681/1860270)​ |
| Skills中心​ | Skill​ | 一种可完成特定任务的模块化能力单元，它将任务所需的知识说明、执行流程、代码脚本、关联资源等要素打包整合，使Agent能够如同调用函数库一般，按需并稳定地执行各类特定任务。​ | [Skill](https://www.volcengine.com/docs/86681/2137204)​ |
| ​ | Skills 空间​ | 支持添加智能体（Agent）开发者已注册的一个或多个Skill，助力Agent快速发现可用Skill，并实现按需逐步加载。​ | [Skills空间](https://www.volcengine.com/docs/86681/2137203)​ |
| 记忆库​ | 记忆库管理​ | 提供企业级的长期记忆管理能力。通过统一接口对接主流记忆库框架（mem0记忆库、Viking记忆库等），帮助Agent实现跨会话的上下文感知、个性化交互和持续学习与演进。​ | [记忆库概述](https://www.volcengine.com/docs/86681/1844855)​ |
| 知识库​ | 知识库管理​ | 提供主流的知识库一键配置导入能力，轻松实现在AgentKit平台关联知识库Agent的部署工作。​ | [知识库概述](https://www.volcengine.com/docs/86681/1883790)​ |
| 网关​ | MCP服务​ | 提供安全可靠的访问入口，通过上传Swagger格式的API定义，批量将存量系统API转换为MCP服务，无需改动代码，快速提升大模型与存量系统的交互能力。​ | [MCP服务](https://www.volcengine.com/docs/86681/1844857)​ |
| ​ | MCP工具集​ | 通过对用户或Agent工具调用的意图和MCP tool描述进行语义匹配，返回匹配程度最高的Server/Tool，提高Tools匹配准确度同时降低大模型调用Token消耗。​ | [MCP工具集](https://www.volcengine.com/docs/86681/1844858)​ |
| 身份与权限​ | 身份管理​ | 通过标准化协议简化企业身份集成，集中管控用户身份入口，降低多系统认证复杂度。支持用户池管理、企业IdP（如SAML/OIDC）及第三方身份联合，提供用户注册、登陆及生命周期管理能力。​ | [身份与权限](https://www.volcengine.com/docs/86681/1873447)​ |
| ​ | 凭据管理​ | 在智能体身份和权限管理平台内托管出站凭据（支持使用API密钥或OAuth客户端），允许Agent、网关使用该凭据访问下游资源。​ | ​ |
| ​  观测​ | 基础监控​ | 提供面向记忆库、MCP服务的基础监控能力，通过多维度指标与可视化面板实时呈现组件状态。​ | * [查看记忆库监控](https://www.volcengine.com/docs/86681/2100988)​  * [查看MCP服务监控](https://www.volcengine.com/docs/86681/2117511)​ |
| ​ | 应用观测​ | AgentKit已与应用性能监控全链路版（Application Performance Management Plus，APMPlus）无缝接入，部署在AgentKit的资源只需要开启观测服务，即可实现资源监控数据的自动接入。接入后可以实现自动收集Trace信息、自动生成Metric指标、以及调用链检索、日志检索等功能。​ | [数据观测](https://www.volcengine.com/docs/86681/1873528)​ |
| 评测​ | | ​ | 通过使用CozeLoop提供的在线实时监控评测能力和离线评测能力（eval），建立完善的在线评测体系，确保Agent服务质量和稳定性，持续优化效果，及时响应用户需求变化，最大化业务价值。​ | * [接入CozeLoop](https://www.volcengine.com/docs/86681/1848568)​  * [Agent 评测](https://www.volcengine.com/docs/86681/1975203)​ |
| 日志​ | | ​ | AgentKit已与火山引擎日志服务TLS无缝接入，部署在AgentKit的资源只需要开启观测服务，启即可实现日志投递与查看。​ | * [开启日志](https://www.volcengine.com/docs/86681/2118195)​  * [查看日志](https://www.volcengine.com/docs/86681/1844827)​  * [日志字段说明](https://www.volcengine.com/docs/86681/1844824)​ |
