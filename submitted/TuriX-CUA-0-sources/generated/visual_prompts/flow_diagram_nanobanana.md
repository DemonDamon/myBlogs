# TuriX-CUA 执行流程视觉描述

[主题与布局设想]
展示 TuriX-CUA 自动化任务执行框架的端到端工作流程图，整体采用从左到右的水平主流向，中间的循环步骤采用S型布局环绕排列，背景为干净的浅灰色，整体逻辑清晰，突出循环执行的核心流程。

[视觉模块详解 (Section A, B...)]
1. **起点模块（最左侧）**：
   胶囊形节点，使用浅蓝色填充，文字内容为「用户输入自然语言任务」，作为整个流程的起点，向右引出实线箭头。
2. **任务分解模块**：
   圆角矩形，使用紫色填充，文字内容为「Planner规划器：分解任务步骤」，向右引出实线箭头连接循环入口。
3. **循环执行区域（用浅蓝色虚线框整体框选）**：
   - 第一个节点为圆角矩形，浅灰色填充，文字为「截取当前屏幕截图」，向下引出实线箭头；
   - 第二个节点为圆角矩形，绿色填充，文字为「Memory记忆模块：整合历史上下文」，向右引出实线箭头；
   - 第三个节点为圆角矩形，橙色填充，文字为「Brain大脑模块：分析截图理解界面状态」，向下引出实线箭头；
   - 第四个节点为圆角矩形，橙色填充，文字为「Brain决策：下一步具体操作」，向右引出实线箭头；
   - 第五个节点为圆角矩形，蓝色填充，文字为「Actor执行器：计算精准点击坐标」，向下引出实线箭头；
   - 第六个节点为圆角矩形，绿色填充，文字为「执行鼠标点击/键盘输入操作」，向右引出实线箭头；
   - 第七个节点为圆角矩形，浅灰色填充，文字为「等待界面更新」，向右引出实线箭头连接判断节点。
4. **判断分支模块（循环出口）**：
   菱形节点，黄色填充，文字为「任务是否完成？」：
   - 向左引出绿色细实线箭头，标注「未完成」，指向循环起始的「截取当前屏幕截图」节点，形成闭环；
   - 向右引出红色实线箭头，标注「完成」，指向终点模块。
5. **终点模块（最右侧）**：
   胶囊形节点，深绿色填充，文字内容为「结束任务」。

[风格与配色方案]
扁平化矢量图风格，按功能分组配色：用户输入层为浅蓝，核心模块（Planner/Brain/Memory/Actor）为深浅蓝色系，执行操作为绿色系，判断分支为警示黄色，整体色调协调统一，字体采用清晰的无衬线黑体，主流程使用粗实线，循环分支使用细实线。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
