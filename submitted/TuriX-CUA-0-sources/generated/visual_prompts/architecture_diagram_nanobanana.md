# TuriX-CUA 架构图视觉描述

[主题与布局设想]
展示 TuriX-CUA 多智能体系统架构的框图。整体采用从上到下的树状布局，核心四大组件居中展示，支撑模块位于底部，背景为干净的浅灰色，突出架构的层次感和模块化。

[视觉模块详解 (Section A, B...)]
1. **顶部入口模块**：最上方为一个深蓝色圆角矩形，标注文字为「用户输入任务指令」，箭头向下连接核心功能区。
2. **中央核心功能区（四大组件）**：四个核心组件采用2x2网格布局，每个组件使用不同色系的圆角矩形框区分：
   - 左上角浅紫色模块：形状为圆角矩形，文字为「Planner 任务规划器」，功能描述小字标注「分解任务步骤」。
   - 右上角浅橙色模块：形状为圆角矩形，文字为「Brain 大脑推理模块」，功能描述小字标注「根据截图理解界面状态、决策下一步」。
   - 左下角浅蓝色模块：形状为圆角矩形，文字为「Actor 动作执行器」，功能描述小字标注「精准坐标定位、执行操作」。
   - 右下角浅绿色模块：形状为圆角矩形，文字为「Memory 记忆管理模块」，功能描述小字标注「维护对话历史与任务上下文」。
   四个核心组件之间用双向细实线互相连接，表示组件间可交互通信，顶部入口模块向下引出箭头指向Planner组件，启动流程。
3. **底部部署与集成模块**：位于核心组件下方，用浅蓝虚线框整体包裹，分为三个子模块：
   - 左侧子模块：灰色圆角矩形，标注「支持热插拔 VLM 视觉语言模型」。
   - 中间子模块：浅蓝色圆角矩形，标注「支持两种部署方式：Ollama 本地部署 / TuriX API 云端调用」。
   - 右侧子模块：浅绿色圆角矩形，标注「通过 MCP 协议 集成外部 AI 助手」。
   核心功能区向下引出主箭头连接该模块区域。

[风格与配色方案]
扁平化矢量架构图风格，整体采用莫兰迪低饱和配色：用户入口用深蓝，四大核心组件分别用紫、橙、蓝、绿区分功能，底部支撑区域用浅蓝虚线框区分层级。字体使用清晰的无衬线黑体，模块文字与背景保持高对比度，线条整洁利落。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准架构图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
