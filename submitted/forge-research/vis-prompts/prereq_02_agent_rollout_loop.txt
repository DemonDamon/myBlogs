[主题与布局设想]
一幅展示 Agent Rollout 循环流程的垂直流程图，突出 LLM 生成、动作解析、工具调用、环境反馈、上下文更新的完整循环。在流程右侧标注关键问题：上下文膨胀、耗时方差、CM 操作时机。底部用两个并排小框展示白盒 vs 黑盒 Agent 在此循环中的可观测性差异。

[视觉模块详解]
顶部：
- 圆角矩形起始节点，标注"初始化：[System Prompt + User Query]"，浅蓝色填充

主循环区域（虚线框包围，标题"Agent Rollout 循环"）：
1. 矩形节点"LLM 生成 a_t ~ π_θ(·|s_t)"，深蓝色填充白字
   - 右侧标注："耗时：0.3~5 秒（纯推理）"
2. 菱形判断节点"解析动作类型"
   - 左侧分支箭头标"工具调用"，指向：
3. 矩形节点"执行工具"，绿色填充
   - 右侧标注框（橙色虚线）："耗时方差极大：API 查询 ~2s / 代码执行 ~300s / 网页爬取 ~30s"
4. 矩形节点"获取环境观测 o_t"，浅绿色填充
5. 矩形节点"更新上下文 s_{t+1} = s_t ⊕ a_t ⊕ o_t"，蓝色填充
   - 右侧标注框（红色虚线）："上下文持续膨胀！可达 200K Token"
   - 从此节点画箭头回到步骤 1，形成循环
   - 菱形判断"CM 检查：上下文是否过长？"
     - 是 → "上下文管理（截断/摘要/筛选）"，紫色填充
     - 否 → 直接回到步骤 1

右侧分支（从判断节点"最终回答"）：
6. 矩形节点"计算奖励 R"，橙色填充
7. 圆角矩形终止节点"输出轨迹 τ"

底部并排对比框：
左框标题"白盒 Agent"：
- 循环中每个节点都有绿色勾号"✓ 可观测"
- 标注："可对每步给过程奖励，CM 纳入训练"

右框标题"黑盒 Agent"：
- 除 LLM 请求/响应外全部灰色叉号"✗ 不可观测"
- 标注："仅观察 API 请求，内部逻辑透明"

[风格与配色方案]
专业学术论文图表风格。LLM 节点使用深蓝色（#1565C0）。工具执行节点使用绿色（#2E7D32）。上下文管理节点使用紫色（#7B1FA2）。奖励节点使用橙色（#FF6B35）。标注框使用对应颜色的浅色版本。箭头使用深灰色（#424242）。循环箭头使用粗线条突出。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 9:16 竖版比例（流程图适合纵向展开）。2K 分辨率。矢量图风格，扁平化设计，专业学术论文图表风格。
