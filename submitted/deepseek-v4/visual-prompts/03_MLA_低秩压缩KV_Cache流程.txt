[主题与布局设想]
一幅展示 MLA（多头潜在注意力）KV Cache 低秩压缩与解压缩流程的水平流程图。整体采用从左到右的流向，分为三个阶段：压缩、缓存、解压+注意力计算。背景为浅灰白色。顶部居中标题："MLA 多头潜在注意力：低秩 KV 压缩"。底部设置一个对比条，展示与 MHA/GQA/MQA 的 KV Cache 大小对比。

[视觉模块详解]

模块 A — 左侧：输入与压缩
一个竖长矩形代表隐藏状态 h_t（高维，标注 d=5120），颜色为蓝色（#1976D2）。
从 h_t 引出两条路径：
路径 1（上方）：经过一个标注"W_DKV 压缩"的窄矩形变换箭头，输出一个明显更小的矩形 c_t^KV（低维，标注 d_c=512），颜色为深绿色（#2E7D32）。这个小矩形用高亮边框标注"仅缓存此向量"。
路径 2（下方）：经过"W_DQ 压缩"变换箭头，输出 c_t^Q（标注 d_c'=1536），颜色为紫色。

模块 B — 中间：KV Cache 存储层
一个大型虚线框区域，标题"KV Cache"。内部是一列竖排的小绿色矩形，每个代表一个 token 的 c_t^KV。与右侧传统方案做对比：用灰色虚影显示传统 MHA 需要存储的巨大 KV 矩阵（被 X 号划掉），旁边标注"传统 KV Cache（93.3% 已压缩）"。

模块 C — 右侧：解压缩与注意力计算
从 c_t^KV 引出两条解压路径：
上方路径：经过"W_UK 解压"箭头，得到多头 Key 矩阵 K（蓝绿色矩形），其中一小部分标注"+ RoPE 位置编码"（解耦部分，用橙色小条表示）
下方路径：经过"W_UV 解压"箭头，得到多头 Value 矩阵 V（青色矩形）
K 和 Q（从上方 c_t^Q 解压得到）汇合进入一个圆角矩形"注意力计算 Softmax(QK^T/√d)·V"，输出为最终的注意力输出（金色矩形）。

模块 D — 底部对比条
一个水平条形图区域，四根横条分别标注：
- MHA: 100%（深灰长条）
- GQA: ~25%（中灰中条）
- MQA: ~6%（浅灰短条）
- MLA: ~4%（绿色极短条，高亮标注"性能优于 MHA"）
标题："KV Cache 大小对比（相对 MHA）"

[风格与配色方案]
浅色学术风格。压缩过程用蓝→绿渐变色系表示维度缩小，解压过程用绿→蓝绿渐变表示维度恢复。关键数据（512、1536、93.3%）用加粗高亮。矩形大小严格反映维度比例关系。

[技术参数建议]
文字必须清晰可辨。保持文字与背景的高对比度。建议 16:9 比例。2K 分辨率。使用标准流程图符号。矢量图风格，扁平化设计，专业学术论文图表风格。
